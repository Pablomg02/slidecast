# Security policy

Please report security problems privately through GitHub's
[*Report a vulnerability*](https://github.com/Pablomg02/syncdeck/security/advisories/new)
form, not in a public issue. Include what you found, how to reproduce it and
its impact. You will get an answer as soon as possible.

Only the latest version on `main` gets fixes.

What syncdeck protects, from whom, and how: [docs/security.md](docs/security.md).
